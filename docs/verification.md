## 内存测量边界

验收脚本记录上传前和上传后、主文件解析完成时的 Docker stats 读数；后一个
时点不保证千文件队列已全部处理。容器上限 1 GiB，具体读数见本次验收报告。
最终核心镜像读数 **35.93 → 51.29 MiB**，扩展镜像 **38.76 → 297.6 MiB**。
较早的扩展验收读数约 **36.38 → 42.73 MiB**；多次读数变化尚未归因，因此
不能用某次较小读数作为内存承诺。科学数据依赖保持可选，默认核心镜像不安装。
32 MiB 负载为合成 CSV；千文件负载包含可复用解析缓存的重复小表。

这些是两个时点的容器内存读数，不是全程峰值、单库 RSS、复杂 PDF/OCR 上限，
也不是对所有语料的性能承诺。大文件源流逐块写盘，解析仅取限定内容样本。
单个解析子进程默认 60 秒、512 MiB 地址空间；复制/备份的哈希按 64 KiB 流计算。
扩展依赖只在相应文件的子进程导入，不常驻 API 进程。

## 数据质量与失败路径

覆盖：CSV 中尾部类型变化、重复/空表头、脏行宽度、缺失值、前导零标识符；
JSON/JSONL、XML/HTML/RTF、Office、PDF 原文/扫描/加密、XOR 图片；只读 SQLite；
科学数组和媒体结构；超时、解析输出超限；内容缓存复用、配方变更重新排队；
过期租约恢复、重新解析的旧结果隔离；新增原生读取器后失效缓存重新排队；
legacy 库迁移与备份恢复。Compose 配置解析检查通过。

上传的指令样本文字没有触发操作。DTD/外部实体、归档路径穿越/符号链接/加密
成员被拒绝解析或展开；成员 CRC 损坏不阻止后续成员导入；不可读的已上传原件仍保留。不用可识别文件头代替读取
成功证明，不将抽样唯一性提升为全量主键约束。

SQLite 提交确认异常的模拟测试验证：即使确认步骤抛错，已提交原件也不能被
误删；无法确认结果时保留原件供校验和恢复。没有自动删除已保存文件的任务。

## 尚未验收的范围

最初附件 `test.zip` 超过平台下载工具 32 MiB 上限，下载调用失败，工作区无其
副本；没有执行针对该附件的解压、逐文件测试、统计或真实内容 schema 校准。
后续可访问文件应运行语料测试脚本，并针对读取失败和低 OCR 置信样本补充适配。

没有公网部署、外部存储卷或真实 Tika 服务验收。未知/私有/损坏/加密内容没有
“所有格式一定可读”的保证；原件保存、读取状态和后续重新解析均可检查。

## Sites Worker 迁移验收（2026-10-08）

部署适配保留原页面，并将上传 API、文件记录、批次分页和下载改为 Cloudflare
Worker + D1 + R2。原件写入 R2，文件元数据和受限的 CSV/JSON 样本 schema 写入
D1。页面逐个流式上传文件，批次不设文件数量上限；单文件上限为 40 MiB。
Sites 私有访问网关仍负责页面与 API 的访问控制，不在浏览器保存站点密钥。

本地 Wrangler 验证覆盖：Worker 构建、健康检查、前端静态资源、多文件批次、CSV
格式识别、样本 schema 行数、记录分页，以及从 R2 下载后与上传原字节逐字节相同。
数据库迁移通过 Wrangler 本地 D1 应用。这个 Worker 不运行原 Python 后端的 OCR、
Office、压缩包递归、科学与媒体读取器；这些本地读取器仍留在源码中，Worker 的
分析响应会明确说明当前支持范围。发布状态需要在实际部署完成后另行核验。
