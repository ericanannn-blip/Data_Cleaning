# 简洁文件工作台

当前界面以文件表格为首页：文件名、格式、大小、格式状态和查看操作。保留“文件 / 结构 Schema / 分类规则”三个工作区，移除了大标题、编号导航卡、三步指南、重复状态指标和成片的小字说明。

## 文件与上传

- 右上角只有一个主要“上传文件”入口，点击后打开上传窗口。
- 关闭窗口或切换工作区不会销毁队列、暂停状态、File 对象或已确认分块。上传状态会显示在页面顶部，可随时重新打开或暂停。
- 目录只加入 DAT，并在浏览器读取 `conversation_asset_file_names.json`；其他格式使用“选择文件”。映射不会作为文件上传。
- 原名映射支持 Windows/Unix 路径，客户端与服务端统一取文件名、移除控制字符、截断至255个UTF-16单元，空结果回退为 `unnamed.dat`。
- 8 MiB 分块、两个文件并行、逐块 SHA-256、非空 ETag 才确认、同名不同内容隔离、相同内容的重复队列项分别保留等行为保持不变。
- 队列只绘制前100条，仍处理全部文件。当前单文件上限以 `/config` 为准。
- 在线 Worker 明确声明支持分块上传时，文件搜索和格式筛选使用 `/files?q=…&type=…`，分页计数指服务端匹配结果。旧 Python 后端未声明该能力时，只筛选已加载记录，输入框及计数明确标示范围；加载更多按未筛选记录数续页，不发送无效的 `q/type` 参数。

## 按需查看

- 点击文件行或“查看”打开右侧详情抽屉，提供原件、检测格式文件名和 schema 下载；关闭后焦点返回触发按钮。
- 抽屉优先显示名称、格式、大小和结构。哈希、完整元数据、规则条件与原始 JSON 收入折叠区。
- 结构 Schema 保留真实分组、关联文件、字段树和筛选结果；结构指纹不再作为主要文案。
- 分类规则以简洁列表呈现，支持搜索及主题/任务筛选；选中后才展示该规则的纳入、排除和边界说明。
- 文件实际分类状态放在独立折叠区。本轮未实现或运行主题分类器，证据不足仍显示未分类。

## 可用性与验证

正文16px，次要信息不小于14px；系统中文字体与等宽字段字体配合。支持系统明暗主题、键盘页签切换、模式记忆、焦点返回、移动端单列和旧异步响应隔离。未经信任的文件名、内容和规则使用文本节点渲染。

`npm run build`、`npm run verify` 和 `node scripts/test-ui.mjs` 用于构建与逻辑回归。UI 测试使用实际前端代码和模拟 API，不代替真实浏览器验收。原件字节一致性由独立实际存储接口测试验证。

布局参考 [Metabase 的数据浏览与详情侧栏](https://www.metabase.com/docs/latest/exploration-and-organization/exploration) 和 [Superset 的数据探索](https://superset.apache.org/user-docs/using-superset/exploring-data/)，按文件管理任务重新组织，未复制其代码或品牌。
